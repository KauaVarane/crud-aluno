# CRUD de Alunos (Java)

Sistema de gestão de alunos em console, desenvolvido em Java, que permite **criar, exibir, atualizar e remover** registros.

## Funcionalidades
- Cadastro de alunos (nome, RA e data de nascimento)
- Busca e exibição por RA
- Atualização dos dados de um aluno
- Exclusão por RA
- Menu interativo em loop: (C)riar, (E)xibir, (R)emover, (A)tualizar e (S)air

## Conceitos aplicados
- Programação orientada a objetos (classes `Aluno` e `GestaoAlunos`)
- Matriz de objetos com 50 posições
- Método `toString()` para exibir os dados
- Manipulação de datas com `LocalDate`
- Entrada de dados com `Scanner`

## Como executar
1. Clone o repositório ou baixe os arquivos
2. Abra em uma IDE Java (IntelliJ, Eclipse ou VS Code)
3. Execute a classe que contém o método `main`
